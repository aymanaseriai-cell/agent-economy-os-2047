# NEXUS-7 2047 — seven cross-disciplinary GitHub research projects

**EXPERIMENTAL, NOT LIVE TRADING.** A distinct new research module, not
installed into the existing automated execution path. Its only real
market input is one frozen BTC-USDT-SWAP public 20 bid + 20 ask L2 book
captured 2026-11-08. Every training/outcome label used by the other
six methods is controlled synthetic data. The study neither proves
profitability nor proves this combination is the world's first.

## Integrated, executed as one pipeline

1. **Cleanlab** identifies deliberately corrupted outcome labels, using
   five-fold out-of-fold predictions on the synthetic dataset.
2. **causal-learn** PC studies conditional dependence and produces an
   observational candidate graph from the same synthetic data.
3. **DoWhy** estimates the known causal treatment effect on those
   synthetic outcomes by controlling the known synthetic regime.
4. **ART (Adversarial Robustness Toolbox)** attacks a synthetic sklearn
   surrogate classifier trained on the same controlled observations,
   measuring actual prediction flips.
5. **GUDHI** computes Vietoris-Rips persistent homology on normalized
   price-size point cloud from the *real* frozen public OKX orderbook.
   The geometry is descriptive and is not a validated prediction signal.
6. **Google DeepMind OpenSpiel** constructs a two-player zero-sum
   ENTER-vs-WAIT, NORMAL-vs-ATTACK matrix game; model payoffs are
   derived from the DoWhy synthetic effect and ART synthetic flip rate.
   This is a hypothetical toy game, not real expected profit or trade
   recommendation.
7. **Microsoft Z3** proves a separate ABSTRACT permission formula
   cannot authorize an order if the user has not enabled live trading
   or if the NVIDIA role has not approved. This DOES NOT prove that the
   existing Python order execution engine implements that formula.

Joint output in reports/nexus7_first_demo_20261108.json carries explicit
synthetic-vs-real source labels, seven status fields, source GitHub URLs
and hard limitations. No private exchange endpoints, passwords, keys,
market orders, leverage or NVIDIA calls are used.

## Safety discipline

- This module has NO write path into the live bot.
- Main real-money workflow remains manually disabled.
- No automatic Actions schedule; separate, explicit manual workflow.
- Python 3.13 isolated research-only environment.
- All seven packages must actually import and be exercised; failure
  stops execution rather than silently substituting made-up numbers.
- Exact package versions listed in trading/requirements_nexus7_research.txt.
- GUDHI core is MIT but specific optional modules have GPL/LGPL dependencies:
  review dependencies and legal obligations before distributing any
  combined commercial application.
- Real-world causal inference needs intervention design, confounder
  control and pre-trade timestamped data; one book snapshot is inadequate.
- No long-term user profits, live trading, predictive alpha or world-first
  implementation is established here.
