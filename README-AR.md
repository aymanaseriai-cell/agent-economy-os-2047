# Agent Economy OS 2047 — اقتصاد الوكلاء القابل للتحقق

**مستودع مفتوح المصدر للتحقق من سلامة الأدلة ومخرجات عمل وكلاء الذكاء الاصطناعي.**

الهدف هو مساعدة مطوري الوكلاء على التأكد من أن الملفات المسلّمة توافق شروطًا تقنية محددة، مع توضيح ما لا تستطيع الفحوص إثباته.

## ابدأ دون مفاتيح أو مدفوعات

يلزم Node.js 24. شغّل من جذر المستودع:

```sh
node examples/proof-carrying-work/run.mjs
```

يُنشئ المثال بيانات اصطناعية، يتحقق من ملف JSON، ثم يغيّر محتواه عمدًا ليثبت أن آلية الفحص ترفض التلاعب.

لتشغيل الاختبارات:

```sh
node --test tests/work_covenant/*.mjs
python3 -m unittest discover -s tests -v
```

[دليل التشغيل بالإنجليزية](docs/QUICKSTART.md) · [الدليل التقني](docs/WORK_COVENANT_2047.md)

## الخدمات المتاحة

- **Proof-Carrying Work Covenant:** شروط قبول تقنية، وتجزيئات SHA-256، وتحقق اختياري من توقيع Ed25519.
- **Evidence verifier:** التحقق من سلامة الملفات باستخدام بيان تجزئات محلي.
- **GitHub Action:** إعادة استخدام التحقق داخل اختبارات CI الخاصة بالمستودعات الأخرى.
- **BountyTruth:** فحوص دفاعية لادعاءات المهام والمكافآت العامة.
- **x402 وProofGate:** أدوات تجريبية للتحقق الأولي من أدلة أو شروط اقتصادية تخص الوكلاء.

## الحدود المهمة

التجزئة المطابقة لا تثبت صدق التنفيذ أو هوية المنفذ أو قبول المشتري. الرد HTTP 402 لا يثبت عملية بيع، والتجارب الاصطناعية لا تثبت الإيرادات. لا ترسل أسرارًا أو بيانات حساسة إلى الخدمات العامة.
