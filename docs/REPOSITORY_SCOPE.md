# Repository scope

Agent Economy OS 2047 is for reproducible, low-dependency **AI-agent evidence integrity**, policy preflight, read-only verification and independent developer integration.

## In scope

- Artifact integrity, deterministic task criteria and typed test results.
- Defensive verification and explicit trust-boundary documentation.
- Authenticated endorsements only when signers are independently trusted.
- Read-only checks of agent commerce statements and independently sourced settlement evidence.
- Reproducible unit tests, offline demos, clear API documentation and GitHub automation supporting these services.

## Out of scope

- Unrelated market-execution systems or account automation.
- Using synthetic demos as sales, buyers, independent acceptance or revenue evidence.
- Automated financial transactions from tutorial examples.
- Claims of audit certification, real-world client adoption or performance without independent evidence.

When submitting a pull request, include the use case, local reproduction instructions, failure cases, and a statement of any financial or network side effects. Keep the default experience offline, free, and safe for developers to test.

**Repository history remains available for prior revisions.** Removing unrelated files in a commit is not equivalent to securely expunging them from Git history; sensitive material requires separate incident-response and history-rewrite procedures.
